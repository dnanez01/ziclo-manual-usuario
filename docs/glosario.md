# Glosario

| Palabra | Qué significa |
|---|---|
| **Almacén** | Trastienda del comercio, donde guarda la mercancía que no está exhibida. |
| **Anaquel** | Estante de exhibición del comercio, a la vista del comprador. |
| **Billetera** | Cuenta virtual de cada cliente donde se acumula su saldo a favor. |
| **Cara** | Unidad de producto visible de frente en el anaquel. Mide la presencia del producto en el estante. |
| **Cliente** | El comercio, no el consumidor: supermercados, licorerías, abastos, bodegones, hoteles y distribuidoras. |
| **Conciliación bancaria** | Verificación con el banco de que un pago registrado coincide con una operación real. |
| **Documento** | Otro nombre para factura, usado en el área administrativa. |
| **DPP** | Descuento por pronto pago. Se aplica solo si el cliente paga dentro del plazo. No depende del vendedor. |
| **Grupo de cliente** | Segmento comercial que determina la lista de precios que le corresponde al cliente. |
| **LISAEA** | Impuesto sobre alcohol y especies alcohólicas. Varía según el grado alcohólico y la categoría del producto. |
| **Nivel** | Clasificación del 1 al 4 según la forma de pago del cliente. Define las formas de cobro habilitadas. |
| **Nota de crédito** | Documento a favor del cliente que se suma a su saldo a favor. |
| **Nota de débito** | Documento que emite Santa Teresa para cobrar una diferencia, por ejemplo por el cambio de tasa. |
| **Punto de venta** | El establecimiento del cliente. No es una caja registradora ni un datáfono. |
| **Saldo a favor** | Dinero del cliente, que viene de notas de crédito o de pagos de más, y que puede usar para pagar facturas. |
| **Solicitud** | Cualquier operación del vendedor que necesita aprobación antes de aplicarse. |
| **Tasa BCV** | Tasa de cambio oficial del Banco Central de Venezuela. |
| **Zanahoria** | Segmento de clientes con el mejor precio, que se gana con buen comportamiento de pago y volumen de compra. |
