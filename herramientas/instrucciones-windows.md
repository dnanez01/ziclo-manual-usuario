# Cómo usar el manual en Windows

Estos archivos son para computadores con **Windows**. Si tu computador es Mac, usa la carpeta **Mac**, que está al lado de esta.

Haz **doble clic** en el archivo de lo que quieres hacer:

| Quiero | Doble clic en |
|---|---|
| **Preparar el computador**, solo la primera vez | **0. Preparar este computador** |
| **Ver el manual** | **1. Ver el manual** |
| **Cambiar algo del manual** | **2. Editar el manual** |
| **Sacar el PDF** para imprimir o enviar | **3. Sacar el PDF** |
| **Enviar el manual** al cliente o a sistemas | **4. Enviar el manual** |

No abras ni cambies nada de la carpeta **sistema**, que está junto a la carpeta **USAR EL MANUAL**. Ahí está el funcionamiento interno del manual.

## 0. Preparar este computador

Esto se hace **una sola vez**, en cada computador donde vayas a usar el manual.

1. Haz doble clic en **0. Preparar este computador**.
2. Si el computador ya está listo, te lo dice y no hace nada más.
3. Si falta un programa llamado **Python**, lo instala solo. Necesitas internet y puede demorar unos minutos.
4. Si no lo logra, te abre la página de descarga. Descarga Python, ábrelo y, antes de instalar, **marca la casilla "Add python.exe to PATH"**.
5. Cuando termine, cierra la ventana. Ya puedes usar los archivos 1, 2, 3 y 4.

La primera vez que uses cualquiera de esos archivos, espera un momento: se termina de preparar solo. Las siguientes veces es inmediato.

Si llevas el manual a otro computador, copia la carpeta **manual-usuario** completa, con **USAR EL MANUAL** y **sistema** adentro, y vuelve a hacer el paso 0 allá.

## 1. Ver el manual

Haz doble clic en **1. Ver el manual**. El manual se abre en tu navegador, con el buscador y el menú. Siempre muestra la última versión guardada.

## 2. Editar el manual

1. Haz doble clic en **2. Editar el manual**. Se abre una ventana negra y el editor en tu navegador.
    - **No cierres la ventana negra mientras editas.** Cuando termines, ciérrala.
2. A la izquierda, elige la página que quieres cambiar, o búscala con el **buscador**.
3. Haz clic sobre cualquier texto y escribe. La página se ve casi igual que en el manual.
4. Toca **Guardar**, arriba a la derecha, o presiona **Ctrl + S**.

Mientras no guardes, arriba dice **Cambios sin guardar** y el botón **Guardar** se pone azul oscuro. Si te equivocas, **Descartar cambios** deja la página como estaba la última vez que guardaste.

### Qué puedes hacer

| Para | Haz esto |
|---|---|
| Cambiar un texto | Haz clic sobre él y escribe. |
| Poner una palabra en negrita | Selecciónala y toca **Negrita** en el recuadro que aparece encima, o presiona **Ctrl + B**. Úsalo para el nombre de los botones de la app. |
| Agregar un paso | Presiona **Enter** al final de un paso, o toca **Agregar paso**. Los números se ponen solos. |
| Quitar un paso vacío | Presiona la tecla de borrar dentro del paso vacío. |
| Poner algo debajo de un paso | Haz clic en el paso y toca **Agregar dentro de este paso**. Elige captura, texto, consejo, cuidado, lista o tabla. |
| Agregar algo en cualquier parte | Pasa el mouse sobre una parte de la página y toca **+** en la barrita que aparece arriba a la derecha. Lo nuevo queda justo debajo. |
| Agregar algo al final | Toca **Agregar bloque**, al final de la página. |
| Mover o quitar una parte | Pasa el mouse sobre ella y usa las flechas o el basurero de la barrita. Si la quitas por error, toca **Deshacer** en el aviso que aparece abajo. |
| Cambiar un recuadro | Haz clic dentro del recuadro y elige **Consejo**, **Cuidado** o **Pregunta frecuente**. |
| Editar una tabla | Haz clic en una celda y escribe. Usa **Fila**, **Columna** o el basurero al final de cada fila. |
| Agregar una captura | Elige **Captura** en cualquiera de los botones para agregar. Arrastra la imagen o elígela, y escribe una descripción corta. |
| Cambiar una captura | Toca **Cambiar imagen** en la captura y elige la imagen nueva. |
| Ver una captura en grande | Haz clic sobre ella. |
| Ver cómo queda en el manual | Toca **Vista previa**, arriba a la derecha. Cada vez que guardas se actualiza sola y te muestra la parte que cambiaste. |
| Volver a una versión anterior | Toca **Versiones anteriores**, arriba de la página. Elige la versión por la hora en que se guardó: lo que cambia se ve resaltado en amarillo. Toca **Volver a esta versión**. |
| Crear una página | Toca **Nueva página**, arriba a la izquierda, debajo del buscador. |
| Eliminar una página | Ábrela, toca **Opciones de la página** y luego **Eliminar esta página**. |
| Recuperar una página eliminada | Toca **Papelera**, abajo a la izquierda, y luego **Recuperar**. |

El título principal de cada página se puede cambiar, pero no se puede borrar. Las partes con rayas que dicen **formato especial** no se editan aquí: pide ayuda técnica.

### Reglas para escribir

- Escribe corto y claro, de tú y en español neutro.
- Usa el mismo texto de los botones de la app, en **negrita**.
- No uses paréntesis para repetir algo que ya dijiste.
- No uses guiones largos.
- Un paso por acción, con su captura debajo.

## 3. Sacar el PDF

Haz doble clic en **3. Sacar el PDF** y espera unos segundos. El PDF aparece en esta misma carpeta con el nombre **Manual de usuario - App Ron Santa Teresa** y se abre solo.

Si cambiaste algo del manual, vuelve a sacar el PDF para que tenga los cambios. Para este paso se usa **Microsoft Edge**, que ya viene instalado en Windows.

## 4. Enviar el manual

Haz doble clic en **4. Enviar el manual** y espera unos segundos. En esta misma carpeta quedan **dos archivos**, uno para cada caso. Elige el que necesites.

| A quién se lo envías | Qué archivo le mandas |
|---|---|
| **Al equipo de sistemas**, para publicarlo en el servidor y que todos entren por un enlace | **Manual de usuario - App Ron Santa Teresa - para publicar en el servidor.zip** |
| **A una persona** que quiere leerlo en su computador | **Manual de usuario - App Ron Santa Teresa - para abrir en el computador.zip** |
| **A quien solo quiere leerlo o imprimirlo** | **Manual de usuario - App Ron Santa Teresa.pdf**, que sale del paso 3 |

Si cambiaste algo del manual, vuelve a hacer doble clic en **4. Enviar el manual** antes de enviarlo, para que incluya los cambios.

### Qué hace cada quien al recibirlo

- **El equipo de sistemas:** dentro del archivo va una hoja con las indicaciones que ellos necesitan.
- **La persona que lo abre en su computador:** descomprime la carpeta y hace doble clic en **ABRIR EL MANUAL**. No necesita instalar nada.

**Ten en cuenta:** quien recibe el manual solo puede leerlo. Para editarlo se necesita la carpeta **manual-usuario** completa, en un computador preparado con el paso 0. Abierto con doble clic, el manual se ve completo sin internet; solo el buscador necesita conexión. Publicado en el servidor, el buscador funciona siempre.

## Si algo sale mal

- **Cerraste el navegador sin guardar:** al volver a abrir la página en el editor, te ofrece recuperar lo que escribiste.
- **Se cerró la ventana negra mientras editabas:** el editor te avisa. No cierres el navegador; vuelve a abrir **2. Editar el manual** y guarda de nuevo.
- **Te equivocaste y ya guardaste:** toca **Versiones anteriores** y vuelve a la versión que quieras. La versión de ahora no se pierde: queda en la misma lista, por si cambias de idea.
- **El PDF o el archivo para enviar no se crea porque está abierto:** ciérralo y vuelve a intentarlo.
- **Aparece un mensaje de error en la ventana negra:** toma una foto de la pantalla y envíasela a soporte técnico.
